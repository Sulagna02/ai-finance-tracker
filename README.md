# ai-finance-tracker
AI-powered finance tracker built using Spring Boot, Spring AI, PostgreSQL, JWT, and React with intelligent expense categorization, financial analytics, budgeting insights, and conversational AI assistant.

Core Features :
 Track income & expenses
 Categorize spending automatically using AI
 Chat with your finances using natural language
 Generate budgeting insights
 Predict monthly spending
 Detect unusual expenses
 Create financial summaries

 Architecture:
Frontend (React/Next.js)
        ↓
Spring Boot REST APIs
        ↓
Spring AI Layer
        ↓
OpenAI / Ollama / Gemini
        ↓
PostgreSQL Database

Additional Requirements:
Redis → caching
Kafka → streaming transactions
AWS S3 → receipt storage
Docker → deployment

TECHSTACK:
| Layer          | Technology            |
| -------------- | --------------------- |
| Backend        | Spring Boot           |
| AI Integration | Spring AI             |
| Database       | PostgreSQL            |
| ORM            | Spring Data JPA       |
| Security       | Spring Security + JWT |
| AI Model       | OpenAI GPT / Ollama   |
| Build Tool     | Maven                 |
| Frontend       | React or Next.js      |
| Charts         | Recharts / Chart.js   |
| Deployment     | Docker + AWS          |
